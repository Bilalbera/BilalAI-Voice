# BilalAI Voice 1.0
BilalAI Voice resmi github reposuna hoşgeldiniz!

# BilalAI Voice Nedir?
BilalAI Voice, terminal veya vs code üzerinden günlük işlerinizi yapmaya yardımcı olmak için tasarlanmıştır. 
(Örn google'da arama yapma, site açma, google'u açma, not defteri açma vb.)

# Nasıl kullanılır?
Öncelikle BilalAI Voice'i sadece terminal ve Visual Studio Code üzerinden kullanabilirsiniz.

## 1. Projeyi bilgisayarınıza indirin:
   
`git clone https://github.com/Bilalbera/BilalAI-Voice.git`
  

## 2. Proje klasörüne girin:
   
`cd BilalAI-Voice`
  

## 3. BilalAI Voice'i başlatın:
   
`python main.py`

projeyi indirdikten sonra .env dosyasına Gemini api key'inizi yazın (Modelin çalışması için gerekli.)

# Özellikler
- 'sesli konuş' komutuyla sesli konuşma ve sesli cevap alma.
- Gemini 2.5 Flash modeliyle entegre edildi.
- Yapay zeka, "hafiza.json" dosyasına bütün sohbetlerinizi kaydeder ve kalıcı bir hafızası vardır.
- Yapay Zeka özel olarak eğitilmiştir.

Bilal Bera tarafından yapılmıştır. Dosyaların izinsiz paylaşılması yasaktır.
